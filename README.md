# RobMOOC
Details of RobMOOC exercises done.

This repository contains elements of corrections of the RobMOOC by Luc Jaulin that you could find at the following address: .


You will find a jupyter notebook with some cleaned answers.

You will find in robmoocpy folder the codes done for the exercices.
The copy verions of a code is the original version of this code.
Some codes have multiple versions (_vX). You should favor the last ones, or the one with no specific versions (no _vX).

You will find in exercices_scanned the hand written pdf scanned exercices done, with some figures.
